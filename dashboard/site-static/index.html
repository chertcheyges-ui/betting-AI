Откуда данные и как обновить снимок

Матчи загружаются из API-Football. В снимке показывается ограниченная выборка с приоритетом крупных турниров. Отсутствующие показатели обозначаются «—»; это не нули.

Кнопка «Открыть последний снимок» перечитывает опубликованный файл. Она не обращается к API и не обновляет счёт в реальном времени.

Для новой выгрузки из папки проекта выполните .venv/bin/python export_fixture_snapshot.py. Затем загрузите файл dashboard/dist/latest-report.json через «Загрузить файл». Для обновления общего сайта новый файл нужно опубликовать.

Подробная статистика запрашивается максимум для трёх уже начавшихся или завершённых матчей. Для остальных доступны расписание и счёт. Сырые API-ключи и настройки аккаунта на сайт не передаются.
