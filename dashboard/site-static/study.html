Что измеряют метрики

Accuracy — доля совпадений наиболее вероятного класса с результатом. При равенстве выбирается первый класс: хозяева, ничья, гости.

Brier score — средняя сумма квадратов ошибок по трём классам. Здесь диапазон от 0 до 2; деления на число классов нет.

Log loss — среднее значение −ln(p) для фактического исхода. Нулевая вероятность фактического исхода даёт бесконечную ошибку.

Случайный равномерный выбор имеет ожидаемую accuracy 33,3%. Для равномерного распределения Brier = 2/3 и log loss = ln(3).

Как интерпретировать результат

Излишняя уверенность может ухудшить Brier score и log loss, даже если доля верных ответов не изменилась.

Один успешный пример не доказывает качество модели. В этом эксперименте вероятности заданы генератором, результаты выбраны случайно по исходному распределению.

Для оценки обученной модели нужна отдельная проверочная выборка, которую не использовали при обучении. Эти метрики сами по себе не проверяют происхождение данных и утечки.

Формат учебного файла

Нужен JSON с полями schema_version: 1, kind: "synthetic_evaluation" и массивом observations. Скачайте встроенный набор как шаблон.

Каждое наблюдение содержит id, названия вымышленных клубов home и away, probabilities: [0.5, 0.3, 0.2] и известный результат actual: 0. Индексы: 0 — хозяева, 1 — ничья, 2 — гости. Вероятности задаются долями от 0 до 1; сумма должна равняться 1 с допуском 0,000001. Набор должен содержать от 1 до 1000 наблюдений. Допустимое округление нормализуется; проценты на экране округляются до суммарных 100%. Файл обрабатывается только в браузере. Учебный набор сохраняется локально; кнопка «Начать заново» заменяет его стандартным примером.
